수원시 인구현황

인증키를 입력하고 [수원시 인구 자동 조회]를 누르세요.
도움말 · URL 직접 입력 · 조회 기록
  1. kosis.kr 에서 OpenAPI 활용신청 후 발급받은 인증키를 위 칸에 입력합니다. (이 브라우저에만 저장됩니다)
  2. [수원시 인구 자동 조회]를 누르면 통계표의 지역·연령·성별 코드를 읽어 수원시 44개 행정동의 연령별·성별 인구를 조회합니다.
  3. 통계표 ID를 바꾸려면 KOSIS의 통계표 URL에 있는 tblId 값을 입력하세요.
  4. 자동 조회가 안 되면 아래 조회 기록의 오류를 확인하거나, KOSIS에서 만든 OpenAPI URL을 직접 붙여넣을 수 있습니다.

최적입지 분석

왼쪽의 시설 위치와 오른쪽의 동별 인구를 합쳐, 인구는 많은데 시설이 부족한 곳을 찾아 신규 설치 위치를 제안합니다.
전체 행정동 점수 보기

● 기존 시설 · ● 추천 입지(번호 핀, 점선 원=서비스 반경) · 동 색이 진할수록 점수 높음
점수 = 인구(많을수록↑) + 시설 부족(인구 1만명당 시설 수가 적을수록↑) + 시설과의 거리(가장 가까운 시설이 멀수록↑)를 가중 평균한 값입니다. 추천 위치는 해당 동 안에서 기존 시설과 가장 멀리 떨어진 지점입니다. 노란색 '가상 데이터' 표시는 실제 데이터가 없어 임의로 만든 값이라는 뜻입니다.
